# Security Policy

## Scope

This project is intended for authorized security research, defensive testing, education, and assessment of systems where you have explicit permission to test.

## Reporting a security issue

Please do not disclose sensitive vulnerabilities, credentials, tokens, or private target information in a public issue.

If you discover a security issue in the framework itself, contact the maintainer privately through the contact information available on the GitHub profile. Include enough detail to reproduce the issue safely, along with the affected file or scan step and any relevant logs with secrets removed.

## Responsible use

Never use this framework against systems without authorization. The presence of a feature in this project does not grant permission to use it against third-party infrastructure.

When sharing scan output for debugging or research, remove credentials, session tokens, personal information, private infrastructure details, and other sensitive data first.
